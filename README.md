# Hema Sekhar

**Computer Vision Dataset Engineer | Founder, Aimage Annotators**

I work hands-on with the data behind computer vision systems — from image and video annotation to object tracking, segmentation, dataset review, and QA.

My focus is on the problems that become important when datasets move beyond simple labeling: **frame-to-frame consistency, object identity, annotation accuracy, edge cases, ground-truth quality, and clear annotation rules.**

Over the years, I've worked with real-world visual data including thermal/RGB video, automotive imagery, maritime data, security environments, and other challenging video datasets.
